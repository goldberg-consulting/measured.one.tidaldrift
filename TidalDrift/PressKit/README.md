# TidalDrift press kit

TidalDrift is an open-source macOS menu bar app for discovering nearby computers, opening remote connections, moving files, and streaming a Mac desktop or app window with LocalCast.

Use the [project README](../../README.md) for current features and installation, the [documentation index](../../docs/README.md) for setup and behavior, and [GitHub Releases](https://github.com/goldberg-consulting/measured.one.tidaldrift/releases) for release-specific changes.

## Short description

Your nearby computers, in the menu bar.

## Product description

TidalDrift brings nearby computers into one menu bar view. Discover services over Bonjour, open screen sharing, file sharing, or SSH connections, and send files with TidalDrop. LocalCast adds remote desktop and app-window streaming between Macs, with remote input and clipboard sharing during a session. A setup guide helps configure the macOS services and permissions each feature needs.

The app targets macOS 13 or later. Features depend on the services and permissions available on each computer; the [Raspberry Pi companion](../../docs/RASPBERRY_PI.md) provides a separate path for Linux discovery and remote access.
